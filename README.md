# Customer Churn MLOps Pipeline

## Project Overview
This project demonstrates an end-to-end MLOps pipeline for customer churn prediction using Flask, Docker, GitHub Actions, and Google Cloud Platform.

## Features
- Data preprocessing
- Model training
- Flask API
- Docker containerization
- CI/CD pipeline
- Cloud deployment on GCP

## API Endpoints

### Health Check
GET /health

### Prediction
POST /predict

## Technologies Used
- Python
- Flask
- Scikit-learn
- Docker
- GitHub Actions
- Google Cloud Platform
